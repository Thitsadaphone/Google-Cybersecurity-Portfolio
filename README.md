## 📂 Featured Projects & Labs

### 1. Security Incident Report & SIEM Log Analysis
* **Tools Used:** SIEM (Splunk / Chronicle), Network Logs, NIST Incident Response Framework
* **Summary:** Investigated simulated security alerts to identify suspicious login attempts and potential unauthorized access. Documented the timeline, affected assets, root cause, and remediation recommendations in a formal incident report.

### 2. Linux File Permissions & Access Control Audit
* **Tools Used:** Linux Command Line (Bash), `ls -la`, `chmod`, `chown`
* **Summary:** Audited user accounts, groups, and sensitive directory permissions on a Linux server. Identified overly permissive files and applied the **Principle of Least Privilege (PoLP)** to secure system access.

### 3. SQL Security Queries & Vulnerability Investigation
* **Tools Used:** SQL, Database Management Tools
* **Summary:** Wrote SQL queries using `JOIN`, `WHERE`, and filtering operators to retrieve login records, identify outdated machines needing security patches, and investigate potential insider threats.

### 4. Python Security Automation Script
* **Tools Used:** Python
* **Summary:** Developed a Python script to automate the parsing of security log files and dynamically update an IP allowlist by removing unauthorized IP addresses.
